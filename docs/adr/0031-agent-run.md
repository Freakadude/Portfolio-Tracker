# ADR 0031: How an agent run works

Status: accepted (2026-10-05)

## Decisions
- **Four steps, as in spec section 11.** *Gather* (a context pack), *investigate* (a tool loop, ending in free-text findings), *compose* (a second, separate call that turns the findings into recommendations with structured outputs, no tools; it is separate because structured outputs cannot be combined with citations), *validate* (the code gate, ADR 0030) and *deliver*. Every call goes through the budget (ADR 0028); the whole trace is kept in `agent_run`: the context pack, every tool call, the findings, the raw answer, the verdict on each recommendation, the prompts' `name@version+digest` labels, tokens (including cache reads and writes) and cost.
- **Thirteen read-only tools, `strict: true`** (`folio/agent/tools.py`): portfolio summary, positions, one position, price history, allocation (with look-through), the strategy (principles and theses word for word), signals, news, macro series, `run_calculator`, `simulate`, recommendation history, and upcoming events (an honest "no calendar is configured yet" until FR-NW-09). The only tool that writes is `run_calculator`, which stores the calculation it made (`calculation` table) and returns `calc-<id>`; the gate later checks that a trade cites one of these and that the figures quoted come from it. A tool that fails returns its message instead of raising, so the model can correct itself.
- **Privacy mode is the default and is enforced in the tools, not asked of the model.** No euro amount of the owner's money is returned (no portfolio value, position values, cost basis, profit in euro, order amounts or remainder): weights, quantities, percentages, per-unit prices and the drift are. Calculator results reach the model as units and weights; Folio fills amounts in itself when it shows an item. With privacy off the amounts are returned and become figures the model may quote.
- **Everything the run sees is recorded as facts.** The ids of signals and news stories shown, the tools called, the macro series fetched, the web pages the search returned (in canonical form) and every number in every result. The context pack is built through the same tools, so what it shows counts as seen. Outside text (headlines, assessments) is wrapped in `<untrusted>` with angle brackets removed, in the pack and in tool results.
- **Web search only with trusted domains.** The server-side tool is offered only when the owner has listed domains (Q12: central banks, issuers, EODHD), restricted with `allowed_domains` and capped by `max_uses`. A paused search turn is continued by sending its blocks back unchanged.
- **Limits.** At most 14 steps in the investigation (then it is cut off with a note, and the compose step still runs on what was found), a per-run token cap, a daily cap of agent runs that does not count the run that is asking, and the monthly budget. A refused call ends the run as `budget`, with one notice; a failed key or network ends it as `failed`; an answer that is not JSON fails the run but keeps what was spent and found.
- **Delivery.** An accepted recommendation is stored (`new`, expiring after its `expires_in_days`) with the last close of each subject that is an instrument, so the track record (phase 5) has a starting point, and goes to the inbox through the notification routing with its own severity, the label "AI-generated, not financial advice", the departs-from-principles note when there is one, and a lock-screen text without names. A refused one is stored as `refused` with its reasons and is never delivered. The daily and weekly reviews also leave their digest as an info item, so a quiet day reads "nothing needs attention" (FR-AG-01).
- **When it runs.** A worker check every five minutes decides what is due and writes nothing when nothing is: the daily review on weekdays from the set time (default 19:30, once a day); an event run for a high or critical signal of the active strategy (once per subject per day) and for a news story at or above the event threshold (once per story); a contribution-plan run for a `contribution_due` signal (off while no plan is set, Q4); and a run asked for by the owner through a job request. At most two runs per check. With the agent off, or without a key, nothing is due and nothing is called.

## Consequences
A run costs a few cents to a few tens of cents depending on tool use, and the cap and budget bound it. The weekly deep review and "ask the portfolio" use the same run (`weekly_review`, `on_demand` with a question) but their schedule and page are phase 5 (FR-AG-07, FR-AG-08).
