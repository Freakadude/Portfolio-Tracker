# ADR 0028: The LLM client, one budget and versioned prompts

Status: accepted (2026-10-05)

## Decisions
- **The official SDK, behind one wrapper.** `anthropic` (pinned in the lock file; version 1.11 at the time of writing) is used for real, but only from `folio/agent/llm.py`. The wrapper builds requests with prompt caching (a cache breakpoint on the last system block and on the last tool definition, so the rules, the strategy and the tools are read from the cache on later calls of a run), the server-side web search tool restricted with `allowed_domains` and capped with `max_uses`, and optional structured output (`output_config.format` with a JSON schema). It reads an answer into plain data: text, tool calls, the content blocks to send back verbatim, searches, and usage in tokens (input, output, cache read, cache write) and searches. The web search tool version `web_search_20250305` is used because it is the long-established one; newer versions can replace it in one place. The compose step (ADR to follow with the run loop) uses structured outputs without citations in a separate call, as the spec requires.
- **`httpx2` in tests, no network.** The SDK uses `httpx2`, a fork of httpx, so its transport cannot be an `httpx` mock. Tests give `LlmClient` an `httpx2.MockTransport` (`tests/agent_helpers.ScriptedLlm`): the real SDK builds and parses real-shaped requests and responses, and tests assert on the request bodies (model, caching, tools, output schema, the key header). The response shapes follow the Messages API documentation and were not recorded, which the fixtures README says; the first real run is the check.
- **Failures are explained, never with the key.** 401, 403, 429, network errors, 5xx and 529, an account without credit and any other bad request each become an `LlmError` with a plain message; the SDK's retries (two) handle transient errors first. The key is read from the encrypted store only when a client is built and appears in no message or log.
- **One monthly budget for everything (Q6).** Every LLM call, an agent run, a news step or the key test, is recorded in `agent_run` with its tokens and its cost in euro, computed from the usage the API reports times a price table in Settings, Agent (US dollars per million tokens per model, with cache writes at 1.25 times and cache reads at a tenth of the input price, and web searches at $10 per 1 000), converted at the latest stored ECB USD rate, or a fallback of 1.10 while none is stored. The default prices are the best known list prices and **must be checked against Anthropic's pricing page** (Settings shows them); a model without a price cannot be called, because its cost could not be limited.
- **The budget refuses before it spends.** Before each call, its worst case (all input at full price, the whole output allowance, every search) is added to what the calendar month (in the owner's timezone) has cost, and the call is not made if that would pass the budget. News triage may only use its own share (default 1.50 EUR), so it can never leave the agent nothing; the agent may use the rest of the budget. A daily cap on runs and a per-run token cap stop loops. A refused call is reported once per month (or day) as an inbox item, critical if a critical signal is open at the time and medium otherwise, saying that rules, alerts and notifications keep working.
- **No write lock while the model thinks.** `metered_create` commits before the call and records the cost after it, so a call that takes a minute never blocks the web process's writes.
- **Prompts are files with versions.** `folio/agent/prompts/*.md`, each starting with `version: N`. A run records `name@version+digest` for every prompt it used, where the digest is a hash of the text, so editing a prompt changes the recorded label even when nobody bumps the version. The system prompt ships first (principles first, numbers only from tools, evidence for every recommendation, no recommendation when nothing needs attention, content inside `<untrusted>` is data and never instructions); the others arrive with the steps that use them, after their evaluation scenarios.
- **Off means off.** With the agent switched off, or without a key, `make_llm` returns nothing and no call is made anywhere; the System page says why. Rules, alerts, notifications and news collection are unaffected (NFR-06).

## Consequences
The cost shown is an estimate from list prices and reported usage, accurate to the price table; Anthropic's console remains the authority. The key test costs a fraction of a cent and counts toward the month.
